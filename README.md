# CA Associates Website
Static HTML pages + a small PHP/MySQL API. Requires PHP 8+, MySQL/MariaDB, Apache (`mod_rewrite`/`.htaccess`).

## Setup
1. Import `database/ca_website.sql` into MySQL.
2. Edit `.env` with your database details.
3. Create the first admin: `php bin/create-user.php "Admin" admin@example.com "StrongPass123" admin`
4. Upload the folder to your web root and open `user/login.html`.

## Editing pages
Header/footer live in `partials/`. Page content is generated by `bin/build-pages.sh`: edit it, set your domain in `SITE=`, then run `bash bin/build-pages.sh` to rebuild all pages, `sitemap.xml` and `robots.txt`.

## How it works
- Home, Services, Calculators, About and Contact are public. Login or My Profile send visitors to the login page.
- `js/common.js` guards every page (`<body data-guard="none|user|staff">`) and loads the header/footer.
- Login sends users to `index.html` and staff/admin to `admin/dashboard.html` (decided in `api/helpers.php`).
- Protected API files call `require_login()` from `api/auth-check.php`; this is the real security layer.
- Use HTTPS in production.
